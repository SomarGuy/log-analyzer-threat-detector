Log Analyzer & Threat Detector: a dependency-free Python tool that parses Linux auth.log (SSH), Windows Security event exports (4624/4625/4672/4688/4720/4732) and nginx/Apache access logs, applies 18 JSON-defined detection rules mapped to MITRE ATT&CK (SSH brute force, password spraying, success-after-failures, new admin accounts, off-hours logins, 404 floods, SQLi/XSS/path-traversal probes, scanner user agents) and writes JSON and Markdown incident reports. A static dark-theme dashboard (canvas timeline, top IPs, MITRE table, filterable alerts, drill-down) shows the results. All sample data is clearly labelled synthetic; the project has 157 pytest tests.
